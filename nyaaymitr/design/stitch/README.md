# Stitch UI Export

This folder documents the Google Stitch design direction for NyaayMitr.

Screens included in the uploaded export:

- `splash_login`
- `nyaaymitr_logo`
- `find_lawyers`
- `client_dashboard`
- `booking_payment`
- `nyayam/DESIGN.md`

The app implementation converts these Stitch screens into Next.js 14 + TypeScript + Tailwind components instead of embedding raw generated HTML.

Design principles:

- Mobile-first citizen experience
- Desktop-friendly legal directory/admin layout
- Deep navy primary brand `#000518`
- Saffron action color `#fe6a2a`
- Gold legal-trust accent `#D4A843`
- Neutral BCI-compliant copy
- No advocate advertising or outcome guarantees
